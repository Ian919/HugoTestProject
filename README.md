# Hugo Test Project

Простой статический сайт на Hugo с кастомными компонентами.

## Что сделано

### Компоненты

- **Article Card** - карточки статей с изображениями и описаниями
- **Review Card** - блоки отзывов с аватарами авторов
- **About Page** - страница о компании с настраиваемым контентом

### Адаптивность

- Мобильные устройства (320px+)
- Планшеты (768px+)
- Десктопы (1024px+)

### Изображения

- Разные картинки для каждой статьи
- Уникальные аватары для отзывов
- Все изображения оптимизированы для веба

### CMS интеграция

- **Decap CMS** (бывший Netlify CMS) настроен
- Визуальный редактор для контента
- Автоматическое сохранение в Git
- Загрузка изображений через интерфейс

## Как запустить

```bash
# Запуск локально
.\hugo.exe server

# Сборка для продакшена
.\hugo.exe
```

Сайт: `http://localhost:1313`

## Структура проекта

```
content/
├── posts/          # Статьи блога
├── reviews/        # Отзывы клиентов
└── about/          # О компании

layouts/
├── partials/       # Компоненты
│   ├── article-card.html
│   └── review-card.html
├── about/          # Шаблоны About
└── reviews/        # Шаблоны отзывов

static/images/      # Изображения
```

## Как добавить контент

### Новая статья

Создать файл в `content/posts/`:

```yaml
---
title: "Заголовок"
date: 2024-01-27
featured_image: "/images/photo.jpg"
draft: false
---
Текст статьи...
```

### Новый отзыв

Создать файл в `content/reviews/`:

```yaml
---
title: "Отзыв"
author: "Имя"
position: "Должность"
company: "Компания"
avatar: "/images/avatar.jpg"
date: 2024-01-27
---
Текст отзыва...
```

## Как использовать CMS

### Локальная разработка

Редактируй файлы напрямую в папке `content/` - изменения видны сразу при `hugo server`.

### Визуальный редактор (для продакшена)

1. Загрузи проект на **Netlify**
2. Включи **Git Gateway** в настройках
3. Открой `https://твой-сайт.netlify.app/admin/`
4. Редактируй контент через веб-интерфейс

### Что можно редактировать через CMS:

- **Статьи** - заголовки, даты, изображения, текст
- **Отзывы** - авторы, аватары, текст отзывов
- **О компании** - все секции, команду, ценности
